# Changelog

> Following [Keep a Changelog](https://keepachangelog.com/en/1.1.0/)
> and [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.2.0] - Unreleased

### Added

- `server`: `RequestVerifier` with a `KeyLookup`, `ResponseSigner`, `Freshness` and `canonical_path`.
- `SignatureInputHeader::parse_received`, `SignatureInput::received_base` and `Headers::received`.
- `SignifyTimestamp::from_unix_micros`.
- Fixtures generated by KERIA.

### Changed

- `SignatureComponent` gains `Unsupported`, which `SignatureInputBuilder::build` refuses.
- `SignatureInputBuilder::expires` is no longer `const`.

## [0.1.0] - 2026-10-09

First release.

### Added

- Validated HTTP header names, values and a bounded, duplicate-free collection.
- The KERI `Signature` header: signages, indexed and unindexed markers, parameters, and a strict
  parser.
- The `Signature-Input` header and the signature base it describes, with the four components a
  KERIA request covers.
- `RequestSigner` and `ResponseVerifier`.
- The `Signify-Timestamp` header value.
- Cross-language fixtures generated by [signify-ts], with generators pinned through npm.

[signify-ts]: https://github.com/WebOfTrust/signify-ts
